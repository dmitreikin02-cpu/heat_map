# Система управления складом - Тепловая карта перемещений

Этот репозиторий содержит инструменты для визуализации складских данных.

## Файлы

### heat_map.html
Инструмент для визуализации тепловой карты перемещений сотрудников по складу.

#### Функционал:
- Загрузка данных из Excel файла (лист "Набор")
- Визуализация частоты посещений мест на складе
- Фильтрация по сотрудникам (конкретный сотрудник или все)
- **Фильтрация по датам** - возможность выбора конкретной даты из доступных
- Фильтрация по этажам мезонина
- **Спагетти-диаграмма** - визуализация маршрутов перемещений с порядковыми номерами
- Интерактивные подсказки с детальной информацией
- **Расширенная статистика**:
  - Количество собранных единиц
  - Время работы сотрудника (формат ЧЧ:ММ)
  - Количество перемещений и посещенных мест

#### Использование:
1. Откройте `heat_map.html` в браузере
2. Загрузите Excel файл с данными о перемещениях (должен содержать лист "Набор" с колонками "Исполнитель", "Место", "Начало выполнения", "Время завершения" и "Количество")
3. **(Опционально)** Загрузите планограмму склада для отображения всех ячеек (лист "Планограмма" с колонкой "Адрес хранения")
4. Выберите сотрудника (или "Все сотрудники")
5. Выберите дату (или "Все даты")
6. Выберите этаж для отображения - статистика будет обновляться для выбранного этажа
7. Включите/выключите режим "Спагетти-диаграмма" для визуализации маршрутов
8. Нажмите "Обновить карту"

**Режим тепловой карты** - цветовая схема показывает интенсивность посещений:
- Зеленый - редкие посещения
- Желтый - средняя активность
- Оранжевый - высокая активность
- Красный - очень высокая активность

**Режим спагетти-диаграммы** - показывает:
- Оптимальные линии между последовательными посещениями через проходы и лестницы
- Порядковые номера посещений рядом с ячейками (цветовой градиент от зеленого к красному)
- Направление движения (стрелки на линиях с градиентом цвета)
- Адрес ячейки и время посещения (из "Начало выполнения") при клике на ячейку
- Все ячейки из планограммы (если загружена) отображаются серым цветом
- **Проходы и лестницы** отображаются вертикальными линиями:
  - Зеленые сплошные линии (↔) - проходы
  - Оранжевые пунктирные линии (🚶) - лестницы

#### Проходы и лестницы:

**Мезонин R:**
- Пролет 10 - проход
- Пролет 12 - лестница
- Пролеты 15-19 - лестница

**Мезонин M:**
- Пролет 27 - проход
- Пролеты 34-35 - проход
- Пролет 41 - проход
- Пролеты 39-44 - лестница

Маршруты строятся только через эти проходы для реалистичного отображения передвижения сотрудников.

### Карта мезонина R-mixed.html
Интерактивная карта мезонина для отображения планограммы склада с информацией о занятости мест.

## Требования

- Современный браузер с поддержкой JavaScript
- Excel файлы с данными в соответствующем формате

## Формат данных

### Для heat_map.html:
Excel файл должен содержать лист "Набор" со следующими колонками:
- **Исполнитель** - ФИО сотрудника
- **Место** - адрес места в формате (например: M101-1-01, R203-5-12, X601-10-05)
- **Начало выполнения** - дата и время начала работы (для определения последовательности и фильтрации по датам)
- **Время завершения** - дата и время окончания работы (для определения последовательности и расчета времени работы)
- **Количество** - количество собранных единиц (опционально, для статистики)

Формат адреса: `[Мезонин][Этаж][Аллея]-[Пролет]-[Место]`
- Мезонин: M, R, или X
- Этаж: цифра (1-7)
- Аллея: двузначное число
- Пролет: число
- Место: двузначное число

**Примечание:** Столбцы с временными метками используются для построения спагетти-диаграммы и определения порядка посещений. Если столбцы отсутствуют, порядок будет определяться по порядку строк в файле.
