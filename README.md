# Система управления складом - Тепловая карта перемещений

Этот репозиторий содержит инструменты для визуализации складских данных.

## Файлы

### heat_map.html
Инструмент для визуализации тепловой карты перемещений сотрудников по складу.

#### Функционал:
- Загрузка данных из Excel файла (лист "Набор")
- Визуализация частоты посещений мест на складе
- Фильтрация по сотрудникам (конкретный сотрудник или все)
- Фильтрация по этажам мезонина
- Интерактивные подсказки с детальной информацией
- Статистика перемещений

#### Использование:
1. Откройте `heat_map.html` в браузере
2. Загрузите Excel файл с данными о перемещениях (должен содержать лист "Набор" с колонками "Исполнитель" и "Место")
3. Выберите сотрудника (или "Все сотрудники")
4. Выберите этаж для отображения
5. Нажмите "Обновить карту"

Цветовая схема показывает интенсивность посещений:
- Зеленый - редкие посещения
- Желтый - средняя активность
- Оранжевый - высокая активность
- Красный - очень высокая активность

### Карта мезонина R-mixed.html
Интерактивная карта мезонина для отображения планограммы склада с информацией о занятости мест.

## Требования

- Современный браузер с поддержкой JavaScript
- Excel файлы с данными в соответствующем формате

## Формат данных

### Для heat_map.html:
Excel файл должен содержать лист "Набор" со следующими колонками:
- **Исполнитель** - ФИО сотрудника
- **Место** - адрес места в формате (например: M101-1-01, R203-5-12, X601-10-05)

Формат адреса: `[Мезонин][Этаж][Аллея]-[Пролет]-[Место]`
- Мезонин: M, R, или X
- Этаж: цифра (1-7)
- Аллея: двузначное число
- Пролет: число
- Место: двузначное число
